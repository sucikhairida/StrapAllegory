## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/StrapAllegory.git`
2. `cd StrapAllegory`
3. Install in editable mode: `pip install -e .`

## Configuration

StrapAllegory is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
